# 音乐文件获取渠道与搜索意图调研

调研日期：2026-09-14。面向中文个人用户，服务于无损系统录音机的产品判断。

## 结论先行

1. 普通用户能找到大量“歌曲下载”入口，真正的困难是拿到**想要的版本、完整、可在其他软件使用的音频文件**。页面写“下载”、App 显示“已下载”和得到普通 MP3/WAV 文件，是不同结果。
2. 搜索生态包含：音乐 App、第三方歌曲聚合站、网盘资源页、格式转换工具、视频提取教程、系统录音工具以及授权音乐库。后四类中的不少页面承接的是“已经能听见，但拿不到可用文件”的需求。
3. 对指定知名歌手或影视歌曲，没有在本轮验证到一个对所有曲目都有效、无需门槛、稳定交付原版普通音频的入口。不能从搜索结果推导“随便找个网站就都能下载”。
4. 本项目适合验证“把有权录制的 Mac 播放声音保存成剪辑素材”，但不是音乐搜索引擎、音源商店或授权渠道，也不能承诺获得母带、分轨或绕过内容保护。
5. 对获客，先验证“Mac 系统声音录制 / Mac 内录 / 网页声音保存”这类贴合产品的词，再验证剪辑任务词。“MP3 下载”覆盖面很广，含大量 Windows、手机、车载用户；当前仅支持 Mac 且导出 ALAC MP4，不宜把这些流量都算作潜在用户。

## 证据与范围

本轮做了中文网页搜索、结果页分类、代表性详情页读取及官方帮助/许可说明核对。搜索工具返回结果不等于百度、必应或 Google 某地区固定前十名；未获得百度指数、广告关键词规划器、搜索日志或访问统计，不能提供月搜索量、市场份额或“用户最常搜”的排名。

“人们可能怎么搜”来自本轮实际输入的查询、页面标题/输入提示以及公开用户提问。公开提问是个案证据，教程和商家文案是供给侧证据，都不是代表性用户调查。工具给出的抓取日期有新有旧，不能把“本日检索”写成所有站点本日更新。

下载验收分为四层：

- A：搜到相关结果。
- B：打开详情，看到目标曲目及下载入口。
- C：真正取得普通音频文件，并检查编码、时长、声音和版本。
- D：确认文件来源及拟定二创用途的授权。

第三方歌曲站本轮最多达到 B；没有完成 C 或 D。代表页面的交互浏览器连续两次超时，网页读取工具可取得静态详情，但不能据此证明动态下载按钮有效。本轮未购买歌曲、未登录第三方下载站、未安装解析软件，也未对受保护内容做解密。

这里把用户说的“源文件”理解为可导入剪辑软件的音频素材。它通常是混合好的成品音乐，不是录音棚工程、分轨或母带。音乐下载、技术保护限制、使用许可也需要分别判断；取得文件不会自动获得公开二创或商业使用的许可。[国家版权局关于短视频音乐使用的说明](https://www.ncac.gov.cn/xxfb/ztzl/jw2021zxxd/202108/t20210805_53638.html)

## 渠道地图：实际能得到什么

| 渠道 | 用户从哪里进入 | 能拿到什么 | 对指定歌曲与二创的限制 |
| --- | --- | --- | --- |
| 主流音乐 App | QQ 音乐、网易云等站内搜歌，再点下载 | 播放/离线权益；能否导出普通文件须看实际曲目、音质、客户端和权限 | 不应把会员下载统一当成普通 MP3。关于 NCM/QMC 等的公开提问反映跨软件使用障碍，但本轮没有逐客户端实测 |
| 官方数字购买/艺人直售 | 支持地区的 iTunes Store、Bandcamp、艺人官网 | 支持的曲目可购买下载普通文件 | 有地区、目录、支付限制；不等于获得视频同步使用或改编授权 |
| 第三方歌曲聚合站 | 搜“歌名 歌手 MP3 下载”“免费下载音乐” | 歌曲详情、播放按钮、下载按钮，有些转网盘或接口 | 版本混杂；页面承诺不能代替下载、音质、完整性及授权验证 |
| 网盘与合集页 | 搜“歌手 合集 无损”“OST 下载”“车载音乐” | 分享链接或压缩包目录 | 本轮未核验包内容、链接有效期、获取门槛及权利来源，不作为推荐下载源 |
| 格式转换类页面 | 搜“下载了打不开”“NCM/QMC 转 MP3”“WMA 转 MP3” | 转换软件/网页或教程 | 普通格式转码与去除技术保护是两类事情；网上教程常有版本限制，不能保证有效 |
| 视频提取 / 系统录音 | 从 MV、短视频或网页播放转到本地素材 | 取决于原视频和采集能力的成品音轨/录音 | 可能有台词、音效、现场声；无法恢复源文件质量；受保护播放不保证可采集 |
| 剪辑平台内置曲库 | 剪映/短视频平台内搜配乐 | 在项目中使用的素材 | 可用范围依具体素材许可；不等于允许导出独立音乐并任意再分发 |
| 明确授权的素材音乐库 | 100Audio、YouTube Audio Library 等 | 素材文件及对应许可条件 | 更适合“不限定必须是某位歌手原曲”的制作任务；不能假设涵盖所需商业歌曲 |

官方核对：

- Apple 说明 iTunes Store 歌曲采用无 DRM（数字版权管理保护）的 256 kbps AAC；中国大陆可用服务表未列 iTunes 音乐购买，香港等地区列有。因此它是部分地区的购买渠道，不能作为中国大陆用户开箱即用的统一答案。[Apple 购买格式](https://support.apple.com/en-om/guide/music/mus3e2346c2/mac)、[地区可用性](https://support.apple.com/zh-cn/118205)
- Bandcamp 官方列出 MP3、FLAC、ALAC、WAV 等购买下载格式。这证明正规普通文件购买路线存在，不证明特定华语歌手在售。[Bandcamp 下载格式](https://get.bandcamp.help/en/articles/15263234-in-which-formats-can-i-download-my-purchases)
- Spotify 官方“下载”帮助描述的是 App 内离线收听；不能把这份说明当成普通 MP3 导出承诺。[Spotify 离线收听](https://support.spotify.com/ly-en/article/listen-offline/)
- 100Audio 提供素材授权购买及 WAV 下载，试听文件和正式授权文件要区分；按项目选择许可，不把其营销承诺扩展到所有用途。[100Audio 购买及授权说明](https://100audio.com/pricing/)
- YouTube 音频库官方说明可下载 MP3，部分条目要求署名，并明确不会替用户判断平台外的全部音乐使用问题。[YouTube 音频库](https://support.google.com/youtube/answer/3376882?hl=en)
- 剪映许可文本明确区分素材用途、期限和平台，单独素材的下载/分发受到限制。适用时应以客户端该素材当时展示的许可为准，不能推断曲库中的音乐都能拿到任意平台使用。[剪映素材许可](https://sf1-cdn-tos.douyinstatic.com/obj/ies-hotsoon-draft/vco/f72e9cd9-cc19-4db7-ba74-0794833ce854.html)

## 用户搜索路径：可检验的行为假设

以下是根据样本归纳的搜索链，不是追踪同一批用户得到的真实行为漏斗：

1. **知道歌名**：`歌名 + 歌手 + 下载` → 加 `MP3`、`完整版`、`原版`。
2. **只记得作品**：`电影/剧名 + 片尾曲` 或 `OST` → 确认歌名 → 再找文件。
3. **先遇到付费或下载门槛**：加 `免费`、`不用会员`、`无损` 等限制词。
4. **下载后无法用**：搜 `导入剪映失败`、`下载的歌在哪里`、`格式转换`，有些继续搜专有扩展名。
5. **转用替代手段**：搜 `视频提取音频`、`Mac 内录`、`网页音频保存`。

第四、第五步更接近本项目能解决的文件获取任务。第二步还包含“识别哪首歌”，目前项目不具备这个能力。

## 对产品立项的修正建议

**调整需求表达，暂不凭搜索结果扩功能。** 原立项的“可验证 ALAC”是可信依据，但用户开始搜索时更可能表达“我要一个能放进剪辑里的音频”。可以用一句更直接的待测文案：

> 把 Mac 正在播放的声音，保存成可用于剪辑的音频文件。

这句文案发布前，需实际验证目标剪辑软件导入；否则仍使用已证实的“保存为本地音频文件”。说明页补充授权范围、全系统混入其他声音以及实时录制所需时长。

建议先验证以下小范围任务：

- Mac 上录下自己或已获许可的声音，导入剪映完成一次裁切、播放和导出。
- 比较当前 ALAC MP4 与 M4A/ALAC、WAV 的导入兼容性；格式转换保真与后缀命名分别检查。结果决定是否提升格式优化优先级。
- 观察用户是否因其他 App 提示音而重录，再决定单 App 录制是否进入首期。
- 用自己制作或明确授权的测试音源，不用下载到文件来代替许可证据。

获客关键词优先级是**产品适配判断**，没有搜索量背书：

| 优先级 | 词组方向 | 原因 |
| --- | --- | --- |
| 先试 | Mac 系统声音录制、Mac 内录音频、Mac 只录声音不录屏 | 操作系统、任务、现有能力吻合 |
| 做完导入验证再试 | Mac 网页声音保存、Mac 音频录制后导入剪映 | 任务链吻合，但须补真实剪辑软件验收 |
| 低优先 | MP3 下载、免费歌曲下载、车载歌曲、WMA 下载 | 流量意图广泛，与 Mac/ALAC 限制错位；不能用现有产品承诺一键下载全曲库 |

下一轮若要作增长投入决策，需要关键词工具或站点实际搜索曝光数据，以及目标用户任务观察。当前结论足以调整待验证场景，不足以得出市场规模或收入预测。
