# 隐私与联网说明（3.2）

本版本提供本地系统音频录制，并要求在线验证版本。录音处理、临时文件及导出均在你的 Mac 上完成，不上传音频；不采集麦克风输入、录音名称、文件路径、音频内容或广告标识。为免登录试用及邀请去重，另使用下文说明的设备凭据和去标识化设备摘要。

## 版本验证

每次开始录音前（包括倒计时结束时）应用向配置的 HTTPS 服务发送应用构建号和一次性随机请求标识，以验证响应确属本次请求。服务器返回带签名的版本策略。断网、验签失败或版本不再允许时不能开始新录音，已经录制的内容仍可停止、保存、导出。

可选的“自动检查更新”只控制 Sparkle 的更新检查，不关闭必要的版本验证。用户同意更新后会下载软件及发布说明；不会因为检查版本自动扣费或自动创建账号。更新服务和网络托管商为传输数据必然能接触 IP 等连接信息，不能将本应用描述为完全不联网。

## 下载统计

普通下载入口按日期和固定来源类别汇总请求次数，不设置追踪 Cookie，不保存请求的 IP、完整 User-Agent，不将不同来源拼接为个人画像；邀请下载另记录下文说明的凭证归因。另读取 GitHub 公开发布资产的下载计数；两个指标分开显示，不相加，也不声称等于独立用户、安装人数或下载完成率。

3.2 新增设备级试用次数、首次使用和邀请关系记录，用于兑现本次活动权益；不据此声称知道真实用户人数。此说明不意味着已经上线收集数据，只有正式服务部署并接入后才产生计数。

## 保存与联系

应用录音由你自行保存和删除。自建服务数据库保留按日汇总的计数及本活动必要的设备权益和操作记录；生产反向代理、托管平台的日志策略也必须与本说明一致地配置并在上线前核对。GitHub 等第三方按其自身政策处理向其发起的请求。

项目反馈入口：[GitHub Issues](https://github.com/359392475-blue-sky/lossless-system-audio-recorder/issues)。请勿在公开问题中提交音频、私钥或个人敏感信息。未来加入账号、支付或新的数据用途时，应更新说明并完成适用的告知及授权。


## 3.2 邀请解锁与免登录试用

首次使用时，应用在本机钥匙串保存一对不经 iCloud 同步的设备签名密钥。读取 Mac 的平台 UUID 后，仅在本地计算本应用专用摘要，不上传原始 UUID、硬件序列号或录音内容。请求包含设备公钥、设备摘要、应用版本系列、构建号、随机请求标识和操作类型；服务端把设备摘要及公钥转换为带服务端密钥的摘要后保存，用于去重和验证。此类可关联设备的数据是去标识化数据，不等于无法关联个人的匿名数据。

邀请服务还保存邀请关系、随机下载凭证、完整安装包发送记录、设备首次成功录音事件、试用次数和当前版本系列的免费权益。不上传录音、音频特征、文件名、保存路径、联系人或好友名单；没有账号登录。成功生成录音时报告一次幂等完成事件，取消/失败报告取消事件；结算失败会在本机保留最少的操作记录并重试。

公开邀请页面不接入第三方广告追踪或跨站设备指纹。安装完成后由用户点击“打开应用并激活”或粘贴激活码关联邀请。下载凭证属于持有者凭证，请勿公开转发个人激活码；邀请链接则可分享。下载完成记录只证明服务已完整发送安装包，结合新的设备身份首次使用判断邀请有效，不代表服务器能读取浏览器磁盘或验证好友的真实身份。

设备去重、已消费的操作标识及已授予的免费权益需在权益有效期间保存，以免重装重复发奖励或丢失权益。生产运营需提供公开的联系与数据删除入口，并规定备份保留周期；删除设备身份会影响免费权益恢复，处理前应告知用户。该联系入口和服务的实际部署属于正式发布前待办。
