# 隐私与联网说明（3.1）

本版本提供本地系统音频录制，并要求在线验证版本。录音处理、临时文件及导出均在你的 Mac 上完成，不上传音频；不采集麦克风输入、录音名称、文件路径、音频内容、设备唯一标识或广告标识。

## 版本验证

每次开始录音前（包括倒计时结束时）应用向配置的 HTTPS 服务发送应用构建号和一次性随机请求标识，以验证响应确属本次请求。服务器返回带签名的版本策略。断网、验签失败或版本不再允许时不能开始新录音，已经录制的内容仍可停止、保存、导出。

可选的“自动检查更新”只控制 Sparkle 的更新检查，不关闭必要的版本验证。用户同意更新后会下载软件及发布说明；不会因为检查版本自动扣费或自动创建账号。更新服务和网络托管商为传输数据必然能接触 IP 等连接信息，不能将本应用描述为完全不联网。

## 下载统计

官方服务仅按日期和固定来源类别汇总下载入口请求次数，不设置追踪 Cookie，不保存请求的 IP、完整 User-Agent 或个人设备标识，不将不同来源拼接为个人画像。另读取 GitHub 公开发布资产的下载计数；两个指标分开显示，不相加，也不声称等于独立用户、安装人数或下载完成率。

当前没有新增录音使用次数、活跃用户或设备级统计。此说明不意味着已经上线收集数据；只有正式服务部署并接入入口后才能产生服务端计数。

## 保存与联系

应用录音由你自行保存和删除。自建服务数据库保留按日汇总的计数，不保存逐用户行为记录；生产反向代理、托管平台的日志策略也必须与本说明一致地配置并在上线前核对。GitHub 等第三方按其自身政策处理向其发起的请求。

项目反馈入口：[GitHub Issues](https://github.com/359392475-blue-sky/lossless-system-audio-recorder/issues)。请勿在公开问题中提交音频、私钥或个人敏感信息。未来加入账号、支付或新的数据用途时，应更新说明并完成适用的告知及授权。
